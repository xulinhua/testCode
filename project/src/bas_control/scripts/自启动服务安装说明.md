# BAS Control 自启动服务配置指南

## 文件说明

- `bas_control_nx16.service` - systemd 服务配置文件（适用于用户 nx16）

## 安装步骤

### 1. 编译工作空间

确保已经编译了工作空间：

```bash
cd /home/nx16/project
colcon build --packages-select bas_control
```

### 2. 复制服务文件到 systemd 目录

```bash
sudo cp /home/nx16/project/src/bas_control/scripts/bas_control_nx16.service /etc/systemd/system/
```

### 3. 重新加载 systemd 配置

```bash
sudo systemctl daemon-reload
```

### 4. 启用服务（开机自启动）

```bash
sudo systemctl enable bas_control_nx16.service
```

### 5. 启动服务

```bash
sudo systemctl start bas_control_nx16.service
```

## 服务管理命令

### 查看服务状态

```bash
sudo systemctl status bas_control_nx16.service
```

### 停止服务

```bash
sudo systemctl stop bas_control_nx16.service
```

### 重启服务

```bash
sudo systemctl restart bas_control_nx16.service
```

### 禁用服务（取消开机自启动）

```bash
sudo systemctl disable bas_control_nx16.service
```

### 查看服务日志

```bash
# 查看所有日志
sudo journalctl -u bas_control_nx16.service

# 查看最近的日志
sudo journalctl -u bas_control_nx16.service -n 100

# 实时查看日志
sudo journalctl -u bas_control_nx16.service -f
```

## 配置说明

### 主要配置项

- **User=nx16**: 运行服务的用户名
- **Group=nx16**: 用户组
- **WorkingDirectory=/home/nx16/project**: 工作目录
- **Environment="HOME=/home/nx16"**: 设置 HOME 环境变量
- **Environment="ROS_DOMAIN_ID=0"**: ROS2 域 ID，可根据需要修改
- **Environment="RMW_IMPLEMENTATION=rmw_cyclonedds_cpp"**: ROS2 中间件实现
- **ExecStartPre**: 预加载环境变量的命令
- **ExecStart**: 实际执行的命令，包括：
  - Source ROS2 环境
  - Source 工作空间环境
  - 运行 bas_control_node
- **Restart=on-failure**: 失败时自动重启
- **RestartSec=10s**: 重启间隔 10 秒
- **LimitNOFILE=65536**: 最大文件打开数限制
- **LimitNPROC=4096**: 最大进程数限制
- **StandardOutput=journal**: 标准输出到系统日志
- **StandardError=journal**: 标准错误到系统日志
- **SyslogIdentifier=bas_control**: 系统日志标识符
- **KillSignal=SIGTERM**: 先发送 SIGTERM 信号（优雅停止）
- **KillMode=process**: 仅终止主进程
- **TimeoutStopSec=30s**: 停止超时时间为 30 秒

## 故障排查

### 服务无法启动

1. 检查日志查看错误原因：
   ```bash
   sudo journalctl -u bas_control_nx16.service -n 50 --no-pager
   ```

2. 确认工作空间已编译：
   ```bash
   ls /home/nx16/project/install/bas_control
   ```

3. 手动测试启动命令：
   ```bash
   source /opt/ros/humble/setup.bash
   source /home/nx16/project/install/setup.bash
   ros2 run bas_control bas_control_node
   ```

### 权限问题

如果遇到权限错误，确保用户 nx16 有执行权限：

```bash
chmod +x /home/nx16/project/install/bas_control/lib/bas_control/bas_control_node
```

### ROS_DOMAIN_ID 冲突

如果网络上有多个 ROS2 系统，可能需要修改 `ROS_DOMAIN_ID` 避免冲突：

1. 编辑服务文件：
   ```bash
   sudo nano /etc/systemd/system/bas_control_nx16.service
   ```

2. 修改 `Environment="ROS_DOMAIN_ID=0"` 为其他值（0-232）

3. 重新加载并重启服务：
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl restart bas_control_nx16.service
   ```

## 注意事项

1. **首次安装**：在安装服务之前，确保工作空间已经完全编译成功
2. **环境变更**：如果工作空间路径或 ROS2 版本变更，需要更新服务文件
3. **日志管理**：定期清理日志文件，避免占用过多磁盘空间
4. **网络依赖**：服务设置了 `After=network.target`，确保网络就绪后再启动

## 卸载服务

1. 停止服务：
   ```bash
   sudo systemctl stop bas_control_nx16.service
   ```

2. 禁用服务：
   ```bash
   sudo systemctl disable bas_control_nx16.service
   ```

3. 删除服务文件：
   ```bash
   sudo rm /etc/systemd/system/bas_control_nx16.service
   ```

4. 重新加载 systemd：
   ```bash
   sudo systemctl daemon-reload
   ```

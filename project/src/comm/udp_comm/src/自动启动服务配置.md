# 自动启动服务配置

## 概述

本文档描述了如何在Ubuntu 22.04系统上配置UDP通信服务的自动启动。

## 系统要求

- Ubuntu 22.04
- ROS 2 Humble
- systemd服务管理器

## 配置步骤

### 1. 创建systemd服务文件

#### UDP服务器服务文件
创建文件 `/etc/systemd/system/udp-server.service`：

```ini
[Unit]
Description=UDP Server for ROS 2 Communication
After=network.target
Wants=network.target

[Service]
Type=simple
User=ubuntu
Group=ubuntu
Environment=ROS_DOMAIN_ID=0
WorkingDirectory=/home/ubuntu
ExecStart=/bin/bash -c 'source /opt/ros/humble/setup.bash && source /home/ubuntu/udp_comm_ws/install/setup.bash && ros2 launch udp_comm_server udp_server.launch.py'
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

#### UDP客户端服务文件
创建文件 `/etc/systemd/system/udp-client.service`：

```ini
[Unit]
Description=UDP Client for ROS 2 Communication
After=network.target udp-server.service
Wants=network.target

[Service]
Type=simple
User=ubuntu
Group=ubuntu
Environment=ROS_DOMAIN_ID=0
WorkingDirectory=/home/ubuntu
ExecStart=/bin/bash -c 'source /opt/ros/humble/setup.bash && source /home/ubuntu/udp_comm_ws/install/setup.bash && ros2 launch udp_comm_client udp_client.launch.py'
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### 2. 重新加载systemd配置

```bash
sudo systemctl daemon-reload
```

### 3. 启用服务

```bash
# 启用UDP服务器服务
sudo systemctl enable udp-server.service

# 启用UDP客户端服务
sudo systemctl enable udp-client.service
```

### 4. 启动服务

```bash
# 启动UDP服务器服务
sudo systemctl start udp-server.service

# 启动UDP客户端服务
sudo systemctl start udp-client.service
```

### 5. 检查服务状态

```bash
# 检查UDP服务器服务状态
sudo systemctl status udp-server.service

# 检查UDP客户端服务状态
sudo systemctl status udp-client.service
```

## 服务管理命令

### 启动服务
```bash
sudo systemctl start udp-server.service
sudo systemctl start udp-client.service
```

### 停止服务
```bash
sudo systemctl stop udp-server.service
sudo systemctl stop udp-client.service
```

### 重启服务
```bash
sudo systemctl restart udp-server.service
sudo systemctl restart udp-client.service
```

### 查看服务日志
```bash
# 查看UDP服务器日志
sudo journalctl -u udp-server.service -f

# 查看UDP客户端日志
sudo journalctl -u udp-client.service -f
```

## 故障排除

### 常见问题

1. **服务启动失败**
   - 检查ROS 2环境是否正确配置
   - 确认工作空间已正确构建
   - 查看服务日志获取详细信息

2. **网络连接问题**
   - 确认网络接口已启动
   - 检查防火墙设置
   - 验证IP地址配置

3. **权限问题**
   - 确保服务文件权限正确
   - 确认用户和组设置正确

### 调试方法

1. **手动测试服务**
```bash
# 手动启动UDP服务器
source /opt/ros/humble/setup.bash
source /home/ubuntu/udp_comm_ws/install/setup.bash
ros2 launch udp_comm_server udp_server.launch.py

# 手动启动UDP客户端
source /opt/ros/humble/setup.bash
source /home/ubuntu/udp_comm_ws/install/setup.bash
ros2 launch udp_comm_client udp_client.launch.py
```

2. **检查环境变量**
```bash
# 检查ROS环境
echo $ROS_DISTRO
echo $ROS_VERSION

# 检查工作空间
ls -la /home/ubuntu/udp_comm_ws/install/
```

## 注意事项

1. **依赖关系**: UDP客户端服务依赖于UDP服务器服务，确保服务器先启动
2. **网络配置**: 确保网络接口在系统启动时已正确初始化
3. **资源限制**: 根据系统资源调整服务配置参数
4. **日志管理**: 定期清理服务日志文件，避免磁盘空间不足

## 安全建议

1. **最小权限原则**: 使用非root用户运行服务
2. **网络隔离**: 在安全网络环境中运行服务
3. **访问控制**: 限制对服务的访问权限
4. **日志监控**: 定期检查服务日志，及时发现异常

## 更新和维护

### 服务更新
当更新服务配置或代码时：

1. 停止服务
2. 更新代码和配置
3. 重新构建工作空间
4. 重新启动服务

### 配置备份
定期备份服务配置文件：

```bash
# 备份服务文件
sudo cp /etc/systemd/system/udp-server.service /etc/systemd/system/udp-server.service.backup
sudo cp /etc/systemd/system/udp-client.service /etc/systemd/system/udp-client.service.backup
```

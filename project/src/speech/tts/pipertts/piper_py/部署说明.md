# Piper语音合成项目部署说明

## 项目关系澄清

### 你的piper_speech项目 vs Piper开源项目

**重要提醒：你不需要下载Piper开源项目的完整源码！**

| 项目 | 作用 | 需要下载的内容 |
|------|------|----------------|
| **你的piper_speech项目** | 完整的Python语音合成包，包含TTS引擎、配置管理、音频生成等核心功能 | 不需要额外下载代码 |
| **Piper开源项目** | 提供预训练的语音模型文件 | 只需要下载模型文件（.onnx和.json） |

cd \\192.168.11.129\testCode\ai_speech\tts\piper_speech

- ✅ 版本兼容性检查和验证
- ✅ 安装完成后自动测试
- ✅ 创建激活脚本方便使用

### 第二步：手动安装（详细终端操作指南）

如果智能安装脚本出现问题，可以按照以下详细步骤手动安装：

#### 1. 进入项目目录
```bash
cd \\192.168.11.129\testCode\ai_speech\tts\piper_speech
```

#### 2. 检查当前Python环境
```bash
# 检查Python版本
python --version
# 应该显示：Python 3.10.12

# 检查pip版本
pip --version
```

#### 3. 创建Python虚拟环境
```bash
# 创建名为speech_env的虚拟环境
python -m venv speech_env

# 验证虚拟环境创建成功
ls -la speech_env/  # Linux/macOS
dir speech_env/     # Windows
```

#### 4. 激活虚拟环境

**Linux/macOS系统：**
```bash
# 激活虚拟环境
source ~/speech_env/bin/activate

# 验证激活成功 - 命令行提示符前会出现(speech_env)
# 例如：(speech_env) user@jetson:~$

# 检查虚拟环境中的Python版本
python --version
```

**Windows系统：**
```cmd
# 激活虚拟环境
speech_env\\Scripts\\activate.bat

# 验证激活成功 - 命令行提示符前会出现(speech_env)
# 例如：(speech_env) C:\Users\user>

# 检查虚拟环境中的Python版本
python --version
```

#### 5. 配置pip源加速安装（可选但推荐）

```bash
# 使用清华镜像源加速下载（国内用户推荐）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip config set global.trusted-host pypi.tuna.tsinghua.edu.cn

# 或者临时使用镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

#### 6. 安装依赖包

**方式一：安装所有依赖**
```bash
# 安装requirements.txt中的所有依赖
pip install -r requirements.txt

# 验证安装进度，应该能看到所有包成功安装
```

**方式二：逐包安装（用于调试）**
```bash
# 如果整体安装失败，可以逐包安装
pip install onnxruntime>=1.14.0          # ARM64架构使用CPU版本
pip install numpy>=1.22.0,<2.0.0
pip install piper-phonemize>=1.1.0,<2.0.0
pip install soundfile>=0.10.0,<1.0.0
pip install pyaudio>=0.2.11,<0.3.0
pip install pyyaml>=6.0.0,<7.0.0
pip install click>=8.0.0,<9.0.0
pip install psutil>=5.9.0,<6.0.0
```

#### 7. 验证依赖安装

```bash
# 检查已安装的包
pip list

# 验证关键包是否安装成功
pip show onnxruntime
pip show numpy
pip show piper-phonemize
pip show soundfile

# 检查版本兼容性
python -c "import numpy; print(f'numpy版本: {numpy.__version__}')"
python -c "import onnxruntime; print(f'ONNX Runtime版本: {onnxruntime.__version__}')"
```

#### 8. 创建便捷激活脚本（可选）

**Linux/macOS:**
```bash
# 创建激活脚本
echo '#!/bin/bash
source ~/speech_env/bin/activate
cd "$(dirname "$0")"
' > activate_speech_env.sh
chmod +x activate_speech_env.sh
```

**Windows:**
```batch
# 创建激活脚本
echo @echo off
call speech_env\\Scripts\\activate.bat
cd /d %~dp0
> activate_speech_env.bat
```

#### 9. 退出虚拟环境
```bash
# 当需要退出虚拟环境时
deactivate
```

### 依赖包版本说明

**核心依赖包版本范围（已优化）：**
- `onnxruntime>=1.14.0` - ONNX模型推理（CPU版本），ARM64架构兼容
  - *重要更新：ONNX Runtime GPU版本不支持ARM64架构，已改为CPU版本*
- `numpy>=1.22.0,<2.0.0` - 数值计算，确保使用numpy 1.x系列
- `piper-phonemize>=1.1.0,<2.0.0` - 文本转音素
- `soundfile>=0.10.0,<1.0.0` - 音频文件处理
- `pyaudio>=0.2.11,<0.3.0` - 音频设备操作
- `pyyaml>=6.0.0,<7.0.0` - 配置文件管理
- `click>=8.0.0,<9.0.0` - 命令行工具
- `psutil>=5.9.0,<6.0.0` - 系统资源监控

### 版本兼容性更新记录

**2024-11-07 更新**：
- 放宽ONNX Runtime版本限制：从`>=1.14.0,<1.17.0`改为`>=1.14.0`
- 原因：验证了ONNX Runtime 1.23.2在Jetson Orin NX Super平台上的兼容性
- 确保支持更高版本的GPU加速功能

### 第二步：下载Piper语音模型

**只需要下载模型文件，不需要下载Piper源码！**

从以下链接下载中文语音模型：

1. **官方模型仓库**：https://github.com/rhasspy/piper/releases
   - 查找包含"zh_CN"或"Chinese"的模型文件

2. **社区模型**（推荐）：https://huggingface.co/rhasspy/piper-voices
   - 搜索中文模型，如"zh_CN-medium"

**需要下载的文件**：
- `.onnx` 文件 - 模型权重
- `.onnx.json` 文件 - 模型配置信息

### 第三步：放置模型文件

将下载的模型文件放入指定目录结构：

```
piper_speech/
├── models/
│   └── zh_CN/
│       └── medium/
│           ├── zh_CN-medium.onnx          # 模型权重文件
│           ├── zh_CN-medium.onnx.json     # 模型配置文件
│           └── config.json                # 额外配置（可选）
```

**目录说明**：
- `zh_CN/` - 中文语言目录
- `medium/` - 中等质量模型（还有其他质量等级如low、high）

## 常见问题解答

### Q: 为什么不需要下载Piper源码？
A: 因为你的`piper_speech`项目已经实现了所有必要的TTS功能，包括：
- ONNX模型加载和推理
- 文本预处理和音素转换
- 音频生成和WAV文件保存
- 配置管理和GPU加速

### Q: 模型文件应该从哪里下载？
A: 优先从Hugging Face社区下载，那里有更多更新的中文模型：
https://huggingface.co/rhasspy/piper-voices

### Q: 如何选择合适的中文模型？
A: 建议选择：
- `zh_CN-medium` - 平衡质量和速度
- 确保模型文件包含`.onnx`和`.onnx.json`两个文件

### Q: 部署后如何测试？
A: 使用项目自带的测试脚本：
- `quick_test.py` - 快速系统验证
- `test_interactive.py` - 交互式测试
- `run_demo.py` - 完整演示

# nova_robot_graspnet

Nova 双臂 GraspNet 仿真插件（Isaac Sim 扩展），独立工程，不依赖其他 simulation 子项目运行时资源。

扩展包路径：`hs.robot.nova_robot_graspnet/`

详细说明见：[hs.robot.nova_robot_graspnet/README.md](hs.robot.nova_robot_graspnet/README.md)

## 快速启动

```bash
conda activate isaac_env
cd ~/testCode
bash simulation/src/nova_robot_graspnet/hs.robot.nova_robot_graspnet/scripts/start_isaac.sh
```

菜单：**Window → Hs Robot Nova Robot GraspNet**

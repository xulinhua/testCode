2. 扩展是什么（实现效果）

  • 在 Isaac Sim 中打开侧栏面板 Ext_Grasing_Scene（抓取场景数据采集）。
  • Load：生成默认地面、定向光、Replicator 相机与 640×480 渲染分辨率；加载固定桌子 USD（mz）；从你勾选的物体类别文件夹中随机选 USD，在给定 XY 矩形内散落并带刚体下落；为地面 / 桌面 / 物体写入语义标签 select_classes（与地面标签 ground 等并存）。
  • Start（collect data）：使用时间戳新建 data_log/<时间>/；写入 info.json（摄像机内参与物体位姿快照）；挂载自定义 Replicator 写入器 LxWriter，批量输出 RGB、语义分割、到相机深度 npy、实例 ID、点云及相关 npy，并把点云+颜色合成为 Open3D 的 lx_data_*.pcd。
  • 每一帧采样前会通过 util.generate_camera_pose 在圆柱区域内随机摆放相机并让视线看向桌面附近随机目标（用于视角多样性）。

4. 依赖与运行时要求

  • Isaac Sim：本机已安装 5.1.0 standalone；扩展源码使用 isaacsim.*、omni.*、omni.replicator.core 等 Isaac Sim 5.x 兼容 API。
  • Python：LxWriter 额外依赖：open3d、warp、numpy（随 Kit 运行时一般已具备）；util.py 需要 scipy。若运行时缺 scipy，请在 Kit 所指 Python 环境中安装。
  • 数据：参与随机生成的每个类别文件夹下须有可用 USD（仅扫描 USD 后缀）；桌子上文所说的 mz.usd 路径必须真实存在。

5. 启用扩展（推荐命令行）

将扩展的父文件夹设为 data_collect_isaac（即包含文件夹 IsaacsimExtGrasping 的那一层）；扩展目录名为 IsaacsimExtGrasping。--enable 需与 extension.toml / 包文件夹名匹配。

cd "/home/hs/Downloads/isaac-sim-standalone-5.1.0-linux-x86_64"

./isaac-sim.sh --ext-folder "/home/hs/testCode/simulation/src/data_collect_isaac" \
  --enable "IsaacsimExtGrasping"

也可用 python.sh omni.kit 等方式启动 Isaac Sim GUI，核心仍是带上 --ext-folder 与 --enable。若你已用 Omniverse Launcher 安装到其它磁盘，请改写上面的 Isaac Sim 根路径。

启动后在菜单中找到 Ext_Grasing_Scene 打开侧边面板；初次打开会为 Viewport docking 留出布局。

6.2 推荐操作顺序

  1. 检查 data/raw_data/ 下各类文件夹已含 USD，且存在 mz/mz.usd。
  2. 勾选参与采样的物体类别。
  3. 设置物体数量与生成范围。
  4. 点击 Load，播放时间线让物体落稳后再点 Start（或直接 Start：位姿快照在按下 Start 的瞬间读取）。
  5. 等待控制台输出完成后，到 IsaacsimExtGrasping/data_log/<时间戳>/ 取数据。

8. 常见问题与备注

  • 只有 OBJ 没有 USD：load_world 仅枚举 USD 后缀，需先把网格转为 USD/USDA/USDC。
  • 语义不匹配：物体语义名来自文件名；须与 global_variables.py 内的 class 名一致或通过逻辑扩展。
  • 小数参数被当成整数：采集圆柱参数在读入时使用了 get_value_as_int()，与界面默认小数不一致时需改源码为浮点读取。
  • 版本差异：若在非 5.1 Kit 运行，请以实际 Isaac Sim Python 兼容性为准做小范围 API 校对。
